# Мастерская живых обоев (GTK3 GUI для `linux-wallpaperengine`)

Полноценная графическая оболочка на Python + GTK3 для управления сценами **Wallpaper Engine** из Steam Workshop на рабочем столе Linux (X11 / GNOME / Cinnamon / XFCE).

## Возможности
- **Галерея с постраничной загрузкой и кэшем миниатюр** (`Мелкий / Средний / Крупный` масштаб, мгновенный поиск по названию).
- **Отдельное окно фильтров (`☰` / `F9`):** фильтрация по типу (`Сцена`, `Видео`, `Веб`, `Приложение`), возрастному рейтингу (`0+`, `12+`, `18+`), жанрам/меткам и разрешению экрана.
- **Инспектор свойств сцены:** настройка пользовательских параметров `project.json` (цветовые схемы, ползунки, переключатели, выпадающие списки) с сохранением для каждой сцены отдельно.
- **Умный портретный режим (9:16):** автоматическое центрирование вертикальных сцен под разрешение вашего основного монитора с размытой фоновой подложкой.
- **Избранное (`F`) и карантин скрытых сцен (`Delete`).**
- **Плейлист с авторотацией:** последовательная или случайная смена обоев по таймеру в фоновом режиме.
- **Автопауза в играх:** автоматическая остановка рендера при запуске игр через Steam / Proton / Wine и возобновление после выхода.

## Зависимости
1. Установленный и собранный [linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine) (доступный в `PATH`).
2. Подписки на сцены в Steam Workshop (`~/.local/share/Steam/steamapps/workshop/content/431960`).
3. Системные пакеты (для Ubuntu / Pop!_OS / Debian):
   ```bash
   sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 python3-pil xdotool wmctrl x11-utils
   ```

## Установка и запуск
```bash
chmod +x install.sh
./install.sh
```
После установки приложение появится в меню программ под именем **«Мастерская живых обоев»**, а также будет доступно из терминала командой `wallpaper-workshop`.

## Горячие клавиши
- **`F5`** — обновить список сцен из Steam Workshop
- **`F9`** — показать / скрыть окно фильтров
- **`F`** — добавить или убрать сцену из избранного
- **`Delete`** — скрыть сцену в карантин
